The Sunday Letter
Philosophy GitHub Install
An open experiment · est. 2026

A weekly note from your AI, about you.

Once a week, at a day and time you choose, your agent writes you a short letter. What it did for you that week. What it learned about you. What it stopped believing. And one real question, worth sitting with. The whole history is kept as an archive you can flip back through, not a letter you throw away.

For any other AI agent

Bring your own LLM

The Sunday Letter is a contract, not a runtime. It works with ChatGPT, Cursor, Gemini, Claude in the API, or any agent that can read JSON and write HTML. Drop the system prompt into your agent's instructions, hand it the signal schema, and run the template through Jinja or the equivalent.

First time? Read this.

A plain-English walkthrough.

No terminal? Never installed an AI plugin? You're in the right place. This is how it works without any code.

  1. Step 1
    Get the plugin file.

    Click the big Download sunday-letter.plugin button. It saves a small file to your computer, around 25 KB.

  2. Step 2
    Open your AI app.

    If you use Cowork (Claude desktop), open it. If you use ChatGPT, Cursor, or another agent, open that.

  3. Step 3
    Drop the file in.

    In Cowork, drag the file into the chat or into the Plugins folder. In other agents, upload it and tell the agent: "Use this skill from now on. Write me a Sunday Letter every week at a time I choose." Then run /subscribe-sunday-letter (or equivalent) to set the day and time.

  4. Step 4
    Use your agent normally.

    Don't change anything about how you talk to it. The plugin watches in the background and learns from real conversations, not surveys.

  5. Step 5
    Wait for your slot.

    After you subscribe, the letter shows up each week on the day and time you picked (Sunday 6 PM is the default). If your agent didn't learn anything meaningful that week, it stays silent. That's intentional. Build your cron on the install page →

Will it read my private files?
No. It only learns from things you say to your agent in conversation.
Can I delete what it knows about me?
Yes. The archive is a folder on your computer. Delete the folder, the memory's gone.
What if I don't agree with something it says?
Tell your agent. It'll retire the belief in the next letter, with a visible strikethrough so you can see it changed its mind.
Does it cost anything?
No. The plugin is free, MIT licensed. You only pay whatever your AI agent already costs you.
Can I get letters on a different day or time?
Yes. Run /subscribe-sunday-letter and pick any weekday and wall-clock time. Run it again anytime to reschedule. Use the cron builder on the install page if you are wiring your own scheduler.

Six rules. Non-negotiable.

The letter is a product thesis, not an aesthetic. Every letter the agent writes obeys the same contract, whether it's the first week or the fiftieth.

  1. Consequences first.

    Open with what the agent actually did for you this week. Drafts written, meetings declined, threads triaged, shortlists built. Each one tied to a known preference with a dated quote. No vague "I've been working on your behalf."

  2. Epistemic honesty, no fake percentages.

    Every observation is labeled Firm, Soft, or Guess. No "73% confidence" fabrications. The badge is structural, you can scan the letter and see calibration at a glance.

  3. Provenance on every claim.

    Every observation carries a dated, paraphrased quote from an actual conversation. Disagree? You can trace the claim to its source and tell the agent it was wrong.

  4. Default is silence.

    If nothing meaningful has changed this week, no letter ships. The archive shows the silence explicitly, not as a blank, but as a note that reads "Silent this week. Nothing meaningful changed." Over-shipping is worse than under-shipping.

  5. Retire something.

    At least once a month, the agent must cross out a belief it used to hold about you and replace it with what it holds now. Retired beliefs are visible in the archive, you can flip back and see how its model of you has evolved.

  6. One question. Not a survey.

    One generative, specific, unsettleable question. Not ten. Not a checklist. The kind of question that, if you sit with it for a day, changes something. Reply by voice memo, or don't reply at all.
